# RDC в DFS Replication: объём передачи при изменении части файла

Материалы к статье: Гаврилова И. В., Козлов П. А. «Влияние использования удалённого
дифференциального сжатия на объём передаваемых данных»
(РГУ нефти и газа (НИУ) имени И. М. Губкина, 2026).

## Что здесь лежит

| Путь | Содержимое |

## Стенд

Две виртуальные машины Windows Server 2025 (Oracle VirtualBox, режим сети
Internal Network, 192.168.50.0/24): SRV1 – контроллер домена `company.local` и отправитель, SRV2 –
получатель. Группа репликации `RG1`, папка `C:\DFSShare`, тестовый файл
`bigfile.bin` объёмом 1 073 741 824 байта случайных данных.

Режим RDC переключается для обоих соединений, но файл изменяется только на SRV1,
поэтому измеряется направление SRV1 → SRV2. Порог `MinimumRDCFileSizeInKB = 64`
(по умолчанию) относится к размеру файла, а не изменения.

## Как повторить опыт

На SRV1 от имени администратора домена:

```powershell
# один уровень объёма изменения, пять повторов
C:\measure.ps1 -ChangeBytes 1048576 -Repeats 5
```

Режим RDC переключается до запуска серии:

```powershell
Set-DfsrConnection -GroupName RG1 -SourceComputerName SRV1 -DestinationComputerName SRV2 -DisableRDC $true
Set-DfsrConnection -GroupName RG1 -SourceComputerName SRV2 -DestinationComputerName SRV1 -DisableRDC $true
Update-DfsrConfigurationFromAD
```

Результаты дописываются в `C:\RDC_Experiment\results_v2.csv`.

## Ограничения

Серии выполнены блоками (все опыты с RDC, затем все без RDC). Повторы шли подряд на одном и том же файле без восстановления исходного содержимого: каждый опыт начинается с версии файла после предыдущего. Поэтому наблюдения не независимы, оценки относятся к последовательному сценарию изменения, а p-значение и доверительные интервалы в `analyze.py` формальные. Для строгого сравнения режимов нужно восстанавливать исходный файл перед каждым опытом и рандомизировать порядок режимов.

Измеряется приращение счётчика DFSR, а не полный IP-трафик: заголовки TCP/IP и служебные протоколы вне счётчика не учитываются, захват трафика (Wireshark, pktmon) не выполнялся. В данных есть три передачи между опытами (вне окон измерения): 242 873 800 байт перед первым опытом 75 % с RDC, 2 150 521 960 байт при переключении на режим без RDC и 1 075 250 980 байт после прерванного опыта (`Status = ERROR`).


Обе ВМ на одном физическом хосте; случайные данные; замена непрерывного диапазона
без вставки; изменения больше 75 % файла не исследовались (равенство объёмов около
99 % получено экстраполяцией); нагрузка на процессор и диск не измерялась.
